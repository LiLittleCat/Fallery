# README screenshots

These PNGs are rendered from Fallery's real WinUI/XAML controls in a separate test process. They are **not desktop captures** or UI mockups. The gallery uses deterministic, original artwork generated by `tools/Generate-ReadmeSamples.py`; no photographs, external downloads, personal files, or embedded camera metadata are used.

The fixture uses an opaque background because the desktop backdrop and native window chrome are outside the XAML capture. It does not demonstrate video rendering: Windows media surfaces are not captured by `RenderTargetBitmap`.

## Reproduce on Windows

Prerequisites: the repository's .NET SDK and Python with Pillow (`python -m pip install Pillow` if needed).

```powershell
python tools/Generate-ReadmeSamples.py
if ($LASTEXITCODE -ne 0) { throw 'Sample generation failed' }
dotnet build Tests/ExperienceChecks/ExperienceChecks.csproj -p:Platform=x64
if ($LASTEXITCODE -ne 0) { throw 'Screenshot build failed' }

$captureExe = Join-Path (Get-Location) 'Tests/ExperienceChecks/bin/x64/Debug/net10.0-windows10.0.22621.0/win-x64/ExperienceChecks.exe'
$env:FALLERY_README_SCREENSHOTS = '1'
try {
    $captureProcess = Start-Process -FilePath $captureExe -WindowStyle Hidden -PassThru
    if (!$captureProcess.WaitForExit(45000)) {
        Stop-Process -Id $captureProcess.Id
        throw 'Screenshot capture timed out'
    }
    $captureReport = Get-Content (Join-Path (Split-Path $captureExe) 'experience-checks.txt') -Raw
    if ($captureProcess.ExitCode -ne 0 -or $captureReport -match 'FAIL' -or
        $captureReport -notmatch 'PASS: three README captures') {
        throw "Screenshot capture failed: $captureReport"
    }
    $captureReport
} finally {
    Remove-Item Env:FALLERY_README_SCREENSHOTS -ErrorAction SilentlyContinue
}
python tools/Refresh-ReadmeImageLinks.py
if ($LASTEXITCODE -ne 0) { throw 'Screenshot link refresh failed' }
```

Inspect `experience-checks.txt` beside the executable for `PASS` and visually review all three PNGs before publishing. Screenshots are written here; generated media, settings and thumbnail caches stay in the ignored `work/readme-demo` directory.

The link-refresh script gives each PNG a SHA-256 suffix and updates both READMEs. Changed images get new paths so Markdown previews cannot reuse the previous image at the same URL. It removes obsolete generated revisions; always run it after capturing, and commit the images together with both READMEs.

## Privacy boundaries

- The capture branch runs before the normal test setup or startup folder loading.
- It rejects unexpected files, folders, links, or image hashes that differ from the generator's manifest.
- Settings and thumbnail caches are isolated; recent locations, favorites, excluded folders and the startup folder begin empty.
- The folder tree contains only `Sample Library` and its generated subfolders. No drives, Desktop/Pictures shortcuts, network locations or user-profile ancestors are loaded.
- Breadcrumbs display only the demo root. File information panels and the settings data-directory field are not shown.
- Only the application's XAML root is rendered. Other windows, notifications, the desktop, taskbar, cursor and account details are outside the capture.
- All sample media is still PNG artwork. Audio is muted with volume zero from startup; no video or audio is opened.
- No production UI is changed to produce these captures. The fixture's neutral background and root aliases are presentation setup for the isolated demo.

The image-generation source is committed; generated sample-media files are not needed to view the README. The screenshots themselves are committed so GitHub can display them without running the application.

## 配图说明

这些图片由实际应用界面渲染，不是桌面截图或重画的界面。样例插画全部由脚本生成，文件树、地址栏、设置与缓存均使用隔离的演示数据。发布前仍需逐张检查，确认没有真实文件、用户路径或桌面内容。

## 界面变更后的维护

重新构建后，截图使用最新生产界面。涉及控件名称、私有方法或导航行为的变更时，同步维护 `Tests/ExperienceChecks/App.ReadmeScreenshots.cs`，不得为配图修改生产界面或绕过清单校验。新增场景时同步 README 图片链接及命令中的成功标识。生成后逐张打开图片，核对布局、语言、缺图、敏感路径及元数据；截图不能替代交互、视频或性能验收。

公开的中英文 README 只保留产品介绍与展示图，不重新加入样例生成、隔离配置或隐私说明段落。维护说明保留在本文。

同时设置 `FALLERY_SETTINGS_SCREENSHOTS=1` 可在 `work/readme-demo` 输出中英文“常规/文件夹”标签内容的诊断图；使用真实控件放入临时预览容器，不代表完整 ContentDialog 外壳。应用标签含真实数据目录，禁止纳入截图。诊断图不提交，运行后清除这两个环境变量。
